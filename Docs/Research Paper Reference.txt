The prior 18-class PlantVillage model could not discriminate between Alternaria solani (Early Blight) and Phytophthora infestans (Late Blight) because both fell under the broad "tomato disease" label. The new 3-class model makes this distinction explicit, which is agronomically critical because the two pathogens require different fungicide chemistries.

4. Model Architecture
Backbone: ResNet-18 (He et al., 2016) — chosen over ResNet-50/34 for edge-deployment constraints (parameter count ↓ 4×).

RSS memory delta during inference: <1 MB (model stays resident in memory pool; no per-inference heap allocation).

The benchmark thresholds (400 ms latency, 2 FPS) are conservative estimates for a Raspberry Pi 4 (Cortex-A72, 4 GB LPDDR4). Actual Pi latency will be 5–20× higher than the M1 figures; ground-truth Pi numbers require re-running benchmark_pi.py on the target hardware.
